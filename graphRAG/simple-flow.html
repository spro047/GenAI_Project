🔍 Knowledge Graph Builder

How It Works

You paste any text (story, article, document) → the AI figures out the characters/things and how they're connected → you see a clickable graph + can ask questions about it.

1

You paste text Input

Paste a story, article, or any text into the sidebar in the browser. Click "Generate Graph". The app also Quick Mode saves graphs in your browser's memory — or Workspace Mode saves them permanently in a database.

⬇
2

AI extracts the "who & what" LLM

The backend sends your text to an AI model (Hugging Face or a local model). It asks the AI: "Find all the entities and their relationships in this text." The AI returns a list of triples like (Harry) — [fights] — (Voldemort).

Before extraction, it may SerpAPI search the web to enrich the text with background info on key entities.

⬇
3

Graph is built NetworkX

Each entity becomes a node (circle). Each relationship becomes an edge (arrow connecting two circles). The code also figures out communities — groups of related nodes — and gives the whole graph a title.

⬇
4

Text is stored for searching ChromaDB

Your original text is split into chunks and stored in ChromaDB (a vector database). This is what powers the "memory" later — so when you ask a question, the system can find the most relevant paragraphs from the original text.

⬇
5

You see the interactive graph D3.js

A beautiful force-directed graph appears in your browser. You can drag nodes around, zoom in/out, click any node to see details, filter by entity type (people, places, etc.), and hover to see relationships. Colors show different communities.

⬇
6

You ask questions & it answers smartly Hybrid RAG

Click the chat icon. Ask "What is the relationship between X and Y?" or "Summarize the whole story."

The answer is built from two sources combined:

🔷 Graph Context — looks at the connections between nodes in the graph
📄 Vector Context — searches ChromaDB for the most relevant original text paragraphs

Both are fed to the AI, which writes you a detailed answer with follow-up suggestions.

⬇
📌

What makes this special?

Most chatbots just search text. This one also understands the structure — the connections between things. So when you ask "How is Harry connected to Dumbledore?", it doesn't just guess from keywords — it traces the actual relationship links in the graph and finds the relevant text paragraphs. That's the "Graph" in GraphRAG.
